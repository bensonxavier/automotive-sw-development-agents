# Issue 2 Change Description

## Summary
This change updates the team structure documentation for the automotive software development agents project to reflect a more complete and scalable operating model.

## What changed
- Added explicit experience-level expectations for each team role.
- Clarified that all team members and agents are expected to be experts in automotive software development within their role capabilities.
- Introduced role-specific skill profiles and competency expectations.
- Added a project-based virtual team instantiation model for repository-driven projects.
- Documented how a master orchestration agent and line-manager agents can assemble and manage a team instance using project-specific skill-definition files.

## Intended outcome
This documentation supports the creation of project-specific virtual teams that can plan, monitor, control, and close work through GitHub issues and repository-backed workflows.
