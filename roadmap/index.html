Automotive SW Agents

From deterministic foundations to roadmap-compliant agent teams.

A staged realization plan for the requirements-to-userstories workflow and its shared Team Coordinator platform. The plan separates testable offline foundations from model, RAG, HITL, and GitHub automation work.

Project home Workflow architecture AUTO-SW-AGENTS project

Current position

Active: deterministic SR Reviewer baseline, issue #9, is in progress. The Markdown parser and SR Analyst foundation are complete. The next compliance work adds RAG boundaries, dynamic rubrics, safety checks, and bounded feedback.

Milestones

Targets assume a constrained free-tier budget and roughly 8–12 focused implementation sessions per month. Dates are planning targets, not deployment guarantees.

Realization sequence

The sequence is deliberately incremental: prove each worker/reviewer contract offline, add roadmap-compliant context controls, complete the local pipeline, and only then automate cross-repository coordination.
